# Digital Forensics File Integrity System

## Overview
This project is a web-based digital forensic system that ensures file integrity using SHA-256 hashing.

## Features
- User Login System
- File Upload
- SHA-256 Hash Generation
- File Verification (Tamper Detection)
- Logs with Timestamp
- Digital Fingerprint Verification

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- Bootstrap
- SHA-256 Cryptographic Hashing

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   python app.py

3. Open browser:
   http://127.0.0.1:5000
